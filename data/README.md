# Dados não versionados

Copiar para esta pasta os ficheiros `atividades.csv` e `wisdm_accel_phone.csv` do kit oficial fornecido pela docente (`2_entregar_aos_grupos.zip`). Estes CSV são deliberadamente excluídos do Git pelo `.gitignore`.

Valores SHA-256 do kit disponibilizado ao grupo:

- `atividades.csv`: `07aabf210b2ad2eb30c4dfda0ba685a3876365b4238d0142ccdd4283ac2cf2ed`
- `wisdm_accel_phone.csv`: `f1d8f9ea78e9726e62c336bbcecf18b730c8f59b2395b5865931c419f859aff2`

Verificar com `sha256sum data/atividades.csv data/wisdm_accel_phone.csv` antes do primeiro arranque da base de dados.
